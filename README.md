# Gemini Chat Exporter

Web版 Gemini (gemini.google.com) で開いているチャットを、Markdown または JSON ファイルとして保存する Chrome 拡張機能です。

## 機能

- 表示中のチャットを **Markdown (`.md`)** または **JSON (`.json`)** でダウンロード
- ユーザー発言と Gemini の回答を順番どおりに抽出
- 回答内の見出し・リスト（階層／順序付き）・表・コードブロック・リンク・数式 (KaTeX) を Markdown に変換
- ファイル名はページタイトルから自動生成（使用できない文字は `_` に置換）

## 出力形式

### Markdown

```markdown
# チャットのタイトル

Exported at: 2026/10/17 12:00:00

---

### User

質問の内容

---

### Gemini

回答の内容

---
```

### JSON

```json
{
  "title": "チャットのタイトル",
  "exportedAt": "2026-10-17T03:00:00.000Z",
  "messages": [
    { "role": "user", "text": "質問の内容" },
    { "role": "model", "text": "回答の内容" }
  ]
}
```

## インストール

開発者モードで読み込みます（Chrome Web Store には未公開）。

1. このリポジトリをクローンまたはダウンロードする
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダを選択する

## 使い方

1. Gemini のチャットページ（`gemini.google.com`）を開く
2. ツールバーの拡張機能アイコンをクリックする
3. 「Markdown 出力」または「JSON 出力」を選ぶ
4. ブラウザのダウンロードとして保存される

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `popup.html` | ポップアップの UI（出力ボタン） |
| `popup.js` | アクティブタブの DOM からチャットを抽出し、ファイルとして保存 |

## 仕組み

- ポップアップ起動時に `chrome.scripting.executeScript` でアクティブタブに抽出処理を注入します。
- `user-query` 要素と `model-response` 要素を順に読み取り、回答 HTML を再帰的に Markdown へ変換します。
- 生成したテキストを `Blob` にして `<a download>` でダウンロードします。

## 必要な権限

| 権限 | 理由 |
| --- | --- |
| `activeTab` | 現在のタブでのみ動作させるため |
| `scripting` | タブの DOM から抽出処理を実行するため |
| `tabs` | アクティブタブの情報（ID・タイトル）を取得するため |

外部サーバーへの通信は行わず、データはローカルでのみ処理されます。

## 注意事項

- Gemini の画面構造（DOM のクラス名・タグ名）に依存しています。Gemini 側の UI が変わると抽出できなくなる可能性があります。その場合は `popup.js` のセレクタを調整してください。
- 表示されていない過去の会話（スクロールで読み込まれていない部分）は取得されません。必要な部分をすべて表示してから出力してください。
- 引用・検索結果カードなど一部の UI 要素は意図的に除外しています。

## 開発

拡張機能用の追加ビルド手順はありません。`popup.js` / `popup.html` を編集したら、`chrome://extensions` で拡張機能を再読み込みしてください。
